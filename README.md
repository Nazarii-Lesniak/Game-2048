# 🎮 Game 2048: Advanced OOP & SCSS Animations

This is an advanced implementation of the classic **2048** game, built with a focus on clean architecture and a smooth user experience. The main goal of the project is to demonstrate object-oriented programming skills in JavaScript and complex mathematical calculations in SCSS for creating animations.

---

## 🔗 Live Preview
You can try the game by following the link:
👉 [**PROJECT DEMO**](https://nazarii-lesniak.github.io/Game-2048/)

---

## 🎨 Design
The project is based on the classic design of the 2048 game with a responsive layout, ensuring a perfect look on both desktops and mobile devices.

---

## 🛠 Technologies Used

* **JavaScript (ES6+ Classes):** All game logic (movements, merging tiles, score calculation) is implemented through an independent `Game` class.
* **SCSS:** Use of nesting, variables, and `@for` loops to dynamically create the coordinate grid.
* **HTML5:** Semantic markup using modern tags.
* **BEM Methodology:** Strict adherence to class naming standards to maintain clean code.
* **LocalStorage API:** Implemented data persistence to save game state.
* **Gulp:** Build automation and asset optimization.

## 🚀 Getting Started

To run the project locally, follow these steps:

1. **Clone the repository:**
    ```bash
    git clone https://github.com/nazarii-lesniak/Game-2048.git
    cd Game-2048
    ```

2. **Install dependencies:**
    ```bash
    npm install
    ```
3. **Start the project:**
    ```bash
    npm start
    ```
